Week 1 Assessment – Employee Analysis
1. Project Description
This project analyses employee and department data using Python and Data Engineering concepts.

The project uses Python, NumPy, Pandas and Matplotlib to process employee information and generate visual reports.

4. Setup Instructions
Step 1: Clone the Repository
git clone https://github.com/muthulakshmim-2905/week-1-assessment.git
Step 2: Open the Project Folder
cd week-1-assessment
Step 3: Create Virtual Environment
python -m venv venv
Step 4: Activate Virtual Environment
venv\Scripts\activate
Step 5: Install Required Libraries
pip install requests python-dotenv pandas matplotlib numpy jupyter
Step 6: Start Jupyter Notebook
jupyter notebook
Open the employee_analysis.ipynb notebook to view the analysis.
